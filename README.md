# Empoli-primavera2324-performance-analysis
Match performance analysis using xG, Invasion Index, ball possession and physical metrics from WyScout and Gpexe

This project analyzes match performance using WyScout and Gpexe data for the 2023/24 season of Empoli U19.

## Metrics used
- Expected Goals (xG)
- Invasion Index
- Ball Possession
- Physical metrics (distance, sprints, accelerations)

## Objectives
- Assess match control and its impact on results
- Study correlation between tactical and physical variables
- Understand how physical effort relates to game dominance

## Tools
- Python (pandas, matplotlib)
- Presentation made in PowerPoint (available in PDF)
